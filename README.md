# Programmazione 1 · Tempo e Tris

Pagina statica per verificare il totale delle tre prove parziali (4, 10, 16) e i due punti bonus.

- **Tris**: almeno metà del voto in ogni prova (2, 5, 8).
- **Tempo**: almeno 15/30 nella somma.
- I bonus valgono solo se il totale è il primo disponibile e il parziale è accettato.
